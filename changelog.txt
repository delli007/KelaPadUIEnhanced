KelaPadUI changelog (newest first)

10/21/2026 - Trading-tooltip cleanup: fixed an accidental global in the deal-rating formatter, passed the hovered item link into purchase-history rendering so armor/weapon quality is evaluated correctly, and limited other-quality link construction to when that tooltip option is enabled.

10/21/2026 - Fixed a Lua error when hovering armor, weapons, or glyphs in bank and trading-house tooltips. The other-quality price rows now guard access to the optional LibItemLink library, and LibItemLink is declared in OptionalDependsOn so it loads before KelaPadUI when installed.

10/21/2026 - Set-name tooltips now override the core format through SafeAddString instead of replacing the SI_ITEM_FORMAT_STR_SET_NAME constant, preserving the numeric string ID for other add-ons. The static audit now rejects direct assignments to SI_* constants.

10/21/2026 - Trading-house confirmation-dialog cleanup: the copied buy/sell/remove dialogs now match current core, the obsolete sell API argument was removed, and the documentation records narration and guild-specific-dialog coverage.

10/21/2026 - Maintenance cleanup: fixed accidental globals in trading-tooltip and sets code, pruned unused constants, removed stale commented assignments, localized the known-item filter label, and stopped warning when optional LibCustomMenu is absent. ATT tooltip-extension access now falls back to a one-day window instead of erroring when the optional extension is missing, and optional MasterMerchant tooltip data is nil-guarded.

10/20/2026 - TTC and ATT now work independently: either provider can enable trading, missing-provider tooltip rows show N/A, and ATT-only graph/guild features are hidden without ATT. The trading XML no longer requires ATT at load time.

10/20/2026 - Trading-house confirmation dialogs now use core ZOS text and narration; KelaPadUI only decorates the dialog data needed for buying and listing history.

10/20/2026 - Tooltip style cleanup: tooltip overrides now change only the properties that differ from core and inherit future core defaults; custom-only styles remain explicit. The static audit now also rejects TODO/FIXME markers and unused virtual templates, and validates LibSets API compatibility.

10/20/2026 - Dead-code cleanup: removed unused set/research constants, utility helpers, settings callbacks, tooltip types/templates/styles, commented-out implementations, and the empty Russian locale; retained the active trading, tooltip, settings, sets, and map-rally features.

10/20/2026 - Changed the gamepad map rally keybind to QUINARY and made it available on the main map instead of only the map options panel.

10/20/2026 - Fixed the gamepad map rally keybind failing because it called the private ESOUI IsShowingCosmicMap helper instead of GetMapType().

10/20/2026 - Fixed the trading-house known-item filter for combination-fragment collectibles.

10/20/2026 - Removed 47 dead localization strings and tightened the static audit to recognize indirect KELA string references and dynamic string prefixes.

10/20/2026 - Companion rapport notifications now use a dedicated event namespace; removed the unused companion event cleanup function.

10/20/2026 - Maintenance pass: flattened KelaPadUI settings into one list with category headings and removed the category submenu; added reload-gated feature toggles with defaults and requirement tooltips; removed obsolete support/donation/message settings; restored trading buying/listing history, retention cleanup, guild statistics, and history icons; centralized the ATT analysis-period fallback and clamped it to 1-30 days; fixed the trading-house setup retry and listing-retention cleanup; removed the nonfunctional one-page trading search; branded the KELAPADUI main-menu entry with a purple champion icon and text tint; cleaned chat-tool registration and research guards; removed the dead crafting-panel file and retired pause-menu notes; added maintenance, settings, and trading-house documentation.

10/19/2026 - Refactor phase 2: reorganized retained Lua/XML into kpui_core, kpui_features, kpui_data, and kpui_compat; made the main-menu entry append-only; removed the retired settings panels and unused settings XML; trimmed unused templates; translated all remaining Russian text to English; kept ru.lua as an English no-op; added the gamepad map-info rally-point keybind; and completed the static manifest/syntax/XML audit.

10/18/2026 - Refactor phase 1: removed Quick Access, old Researching, old Undaunted scene, broken rally experiment, KelaPadUIBuyingData, and KelaPadUIListingData; split companion, dungeon-finder/pledge, chat, and trial-link code into feature modules; added a gamepad group-rally-point button in the map info screen; trimmed dead XML/settings/templates; retired Russian text in favor of English while keeping ru.lua; preserved commented debugging code and added DEBUG_NOTES.md; added OPTIMIZATION_TODO.md for deferred trading-house/tooltip work.
